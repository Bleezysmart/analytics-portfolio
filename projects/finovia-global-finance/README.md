# Finovia Global Finance Loan Portfolio Analysis

**Power BI Financial Analytics Case Study · 2026**

Finovia is a loan portfolio analytics project built to provide an interactive view of loan operations, outcomes and overall finance performance.

## Business questions

The project is structured around three analytical views:

- **Finance performance** — understand the overall portfolio and financial position.
- **Loan operations** — examine operational activity across the loan portfolio.
- **Loan outcomes** — investigate how loans perform across outcome categories.

## Solution

The analysis was developed in Power BI using a multi-page dashboard structure. Separate views for finance, loan operations and loan outcomes make it possible to move from executive-level performance into operational and outcome-level detail.

## Deliverables

- Power BI dashboard workbook
- Finance dashboard
- Loan Operations dashboard
- Loan Outcomes dashboard
